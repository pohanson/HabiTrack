**Team Name**: HabiTrack

## Setup Instructions

### Preview 
2 Main Ways:

1. Have an Android device or emulator. Download the apk file and install directly here:
https://expo.dev/artifacts/eas/nH7P1REBWThguRXw3wy9XF.apk

2. Go to the link and click install. Follow the instructions provided there:
https://expo.dev/accounts/pohanson/projects/HabiTrack/builds/afcd9a86-3c1f-455b-87ae-a8c9ca8d7fdd

### Development (for Team Member only)
1. Follow the instructions on the website to download npm:
https://docs.npmjs.com/downloading-and-installing-node-js-and-npm
3. Ensure you have git installed: https://git-scm.com/downloads
4. Open the terminal, run `git clone https://github.com/pohanson/HabiTrack.git`
5. Then `cd HabiTrack/HabiTrack; npm install` to install all the packages we used
6. Add credentials to the `.env` files
7. Use eas to build the developer's build and install on the testing device
8. Run `npm run start` to start the development build.
